FareBloom – Commute Fare Calculator

Description

FareBloom is a simple mobile-friendly commute fare calculator that helps users calculate and track their transportation expenses.

Features

Calculate commute fares automatically

Add commute records

View commute history

Edit and delete commute records

View daily expenses

View weekly expenses

View monthly expenses

Export commute history as CSV

Save commute records using local storage

Installable as a Progressive Web App (PWA)

How to Install and Run

Open the FareBloom project.

Make sure all project files are in the same folder.

Open index.html using a web browser.

To install the app, open the hosted HTTPS version in a supported browser and select the Install App or Add to Home Screen option.
